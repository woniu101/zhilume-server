# 统一节点编辑区验收（2026-09-29）

Studio 0.16.0 / Server 0.13.2；Worker 未修改。

## 实现

四类编辑区共享 ComposerLayout；正文独立滚动、模式/辅助操作/状态/底部操作固定。图片和视频优化提示词与字数同行，执行端选择收进参数，音色参考可直接试听。节点工具栏将跨类型与整理操作放入“更多”，版本入口在标题栏。文本正文编辑草稿和生成要求分别持久保存，不互相覆盖。

## 验证

- Studio 单元测试 11/11；Server 草稿与执行端状态专项 3/3，包含两个文本草稿字段的类型、空值和长度边界。
- 浏览器首次广泛回归 21 项：17 通过、4 失败。其中节点工具栏被居中编辑区遮挡导致 3 项失败，改为避让工具栏；Web 截取任务的一次对话框关闭等待超时，复测通过，未放宽断言。修正后运行焦点、四类小窗口布局、媒体工具和节点结果专项共 8 项，8/8 通过。其余图片、语言、视频、语音交互在首次回归已通过。
- 新布局用例覆盖 700/900/1100 × 720 窗口，四类节点长内容输入，固定区边界，以及离线图片规格的加入队列按钮。截图见 evidence/0.16.0/layout-*.png。
- 打包 Studio 原生 UI 实测：打开隔离项目、单击图片节点、模式/辅助行/状态/固定底栏完整、打开输出参数浮层、Esc 只关闭浮层并保留编辑区。截图 native-image.png / native-output-panel.png。
- Studio build/pack 成功；release/win-unpacked 的 ASAR 版本 0.16.0，3 个 dist 文件与构建逐字节一致。ASAR 校验首次使用正斜杠路径失败，改用 Windows 原生路径后通过。
- 用户退出 Server 后完成固定 release/win-unpacked 打包。首次 EXE 资源写入遇到 EBUSY，确认无进程残留后重试成功；ASAR 版本 0.13.2，dist/admin-dist 共 23 个文件与构建逐字节一致。使用打包 EXE 的 Node 运行模式和隔离数据验证：两个草稿独立保存读取成功（HTTP 200），错误正文草稿类型被拒绝（HTTP 400）。原生 Studio 验收和 Server 冒烟均不接触用户项目。

## 边界

没有运行 GPU 或调用外部计费模型。语言服务、Worker 就绪能力部分使用测试夹具；媒体测试包含本机真实 FFmpeg。Vite 仍记录 ResizeObserver 通知警告，未隐藏该告警；本轮固定区几何断言及媒体流程均通过。真实 GPU 画质、性能沿用独立验收记录。
