# 服务连接与统一空节点验收

Studio 0.19.0 / Server 0.14.0 / PRD v0.39。Worker 源码和 3.0 传输协议未改变；Studio 控制接口升级到 3.1。

## 实现

- 共享连接管理器负责会话探测、超时、退避重试和授权恢复。首页与画布共用服务连接入口，支持最近使用、连接名称、启动自动连接、重连、断开和忘记。
- Server 身份在数据目录持久化；24 小时访问会话配合 30 天轮换续期授权。服务端仅保存密钥散列，续期在事务内消费旧授权并作废旧访问会话。提供设备会话撤销接口。
- 桌面凭证通过系统加密保存；Web 仅保留在当前标签会话。切换成功后才更改活动连接，草稿按服务身份隔离，迟到响应和旧工作区请求不会污染新服务。
- 项目首页不再把加载失败显示为没有项目。Worker 数量与 Server 状态独立；离线暂停业务轮询，恢复后刷新并保存草稿，不自动重发生成请求。
- 四类空节点统一 280×176 默认尺寸、图标/文案/操作；上传和文本编辑入口明确。文件可拖入空节点，素材缺失保留加载重试状态。有内容时音频采用 108px 播放器，图片视频跟随素材比例。

## 验证过程

- 初轮连接/空节点及编辑区交互 7/7 通过。
- Studio 单元测试 10/10；Server 测试 33 项通过、1 项 Linux 平台测试跳过。包括服务身份重启保持、续期并发只成功一次、旧授权失效、撤销访问。
- 扩展界面回归 25/26 通过，发现音频替换操作与播放设置重叠。将替换操作放入播放控制行后，继续发现播放器旧原生 select CSS 未覆盖自定义选择器、视频控制栏偏高，已同步修正。
- 真实 GPU 推理不在本轮验收范围。构建仍有既有大分包提示，开发模式仍有 ResizeObserver 通知警告；未屏蔽这些提示。

最终复测、打包和桌面验收结果见下文。
