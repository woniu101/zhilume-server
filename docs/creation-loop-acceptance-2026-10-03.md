Studio 0.20.0 / Server 0.15.0 / Worker 0.12.1（本轮未修改 Worker）。PRD v0.40。Studio 控制协议 3.1、Worker 传输协议 3.0 保持不变。

## 本轮修复

1. **真实 Worker 成功但节点空白。** 真实语言任务完成、文本文件已归档，但 `/node-results` 没有对应记录。Worker 完成分支直接写 job，绕过了结果账本逻辑。现抽取共享 `recordJob`，将 Worker 素材发布、任务成功与节点结果记录放在同一事务，提交后再发 `commit_ack`。四类 Worker 集成全部新增目标节点及结果唯一性断言。
2. **保存响应丢失后的假冲突。** Studio 记录未确认写入，重试前对照 Server 内容；只有完全匹配上次提交才推进 revision，再保存用户后续编辑。其他窗口的不同内容仍触发冲突，不自动覆盖。
3. **授权自动续期后未保存内容未恢复。** 健康状态可能一直保持 online，因此仅监听状态变化不够；续期成功显式通知工作区保存草稿。
4. **异步准备期间切换服务。** 文本和批量生成在保存前捕获连接代次，切换后拒绝旧提交。草稿键固定为工作区所属服务；断开后迟到的连接响应不重新激活服务。有效保存会话重连先验证访问授权，不无故轮换设备授权。

## 真实 GPU 验收过程

已有上海二 A RTX 5090 32GB 实例，Worker 0.12.1；复用模型，不下载权重。用户已获 GPU 运行通知。操作者临时 SSH 转发用于验收，未增加产品隧道功能；本轮不能证明云平台公网转发长期稳定。

使用 `scripts/accept-creation-loop.mjs --execute`，真实 Studio Web 点击提交，无生成接口拦截。每个成功样本检查节点原位采用、唯一节点结果记录、画布保存、刷新重开及产物 SHA-256。图片 5 步，视频 512×288 / 124 帧 / 20 步，属于执行样本，不作为最终质量基准。

准备阶段旧验收目录绑定与当前 Worker 不同，未修改云端绑定，改用当前 Server 连接身份的隔离副本；浏览器改走已有 Vite 同源代理，未放宽 CORS。另修正验收脚本文本按钮重名定位。上述失败均发生在真实任务提交前。

第一笔真实语言任务暴露本轮的节点结果缺失问题，任务成功但画布没有正文，作为失败保留。修复后完整流程先通过 9 个样本：文本、2512 文生图、2.1 编辑、2.1 双图参考、语音、H3 文生视频/首帧/尾帧/不同图片首尾帧。随后 Ref2VA 准备草稿漏填图片参考的 start/frames，被输入校验拒绝，未启动推理；修正脚本后单独复测，避免重复运行已通过样本。

## Windows 原生验收

使用打包 Studio 0.20.0 与打包 Server 0.15.0、隔离数据目录和同一真实 GPU Worker。`prepare-native-creation.mjs` 只准备测试项目、会话、草稿与运行环境；生成按钮、媒体播放、返回首页及重新打开项目均通过 Windows 原生窗口操作完成。

四类任务均由 EXE 点击提交，最终 4 个成功任务、4 条唯一节点结果、4 个原节点采用素材且画布已保存。视频播放进度到 5.16 秒，语音到 3.27 秒；返回首页后重开项目，四类内容与完成状态保留。见 [原生结果记录](evidence/native-creation-2026-10-03.json) 与 [重开截图](evidence/native-creation-2026-10-03.jpg)。本轮原生重开指项目重开，不扩展为所有系统崩溃恢复场景。

截图也保留了一个布局边界：图片采用实际比例后变高，可能与手工放置的下方节点重叠。自动避让不在本轮 P0 范围，后续画布布局迭代应覆盖。

结束时隔离 Studio、Server 与转发脚本均退出；转发线程在关闭连接时记录一次 WinError 10054，主验收进程退出码为 0，四个结果已事先写入并确认。上海 5090 实例已通过云 API 确认 `Stopped`。
