# 节点生成与结果版本规范（2026-09-29）

本轮直接重构初版的节点结果归属，不迁移旧开发版本自动创建的结果节点。Studio 0.15.0 与 Server 0.13.0 配套使用；Worker 执行协议仍为 3.0。

## 创作操作

- 默认创建明确类型的节点。仅无内容、无历史、无连线、无成功或在途任务时，可以在编辑区切换文本／图片／视频／音频。系统名称随类型重新编号，用户名称由 titleSource=custom 标识并保留。各类型草稿独立保存。
- 图片、视频、语音、文本生成和重复生成均更新目标节点，并保留历史版本。提交不关闭编辑区，不增加结果节点或装饰连线。
- 执行时保留原内容，以阶段、真实百分比、取消入口覆盖展示。允许编辑下一次草稿；同节点当前任务结束前不能再次提交，不同节点可并行。
- 历史可预览、下载、采用或另存为新节点。采用历史不删除新版本。删除节点不取消后台任务，也不会被晚到的结果重新创建。
- 图片转视频、文本转图片／语音先创建对应类型的目标节点并带入已有参考内容，不把源节点改变类型，不自动重跑上游。
- 裁剪、视频截取默认更新当前节点并保存原内容为历史；拼图、宫格切分保留来源并创建输出节点；提取音轨创建音频节点。裁剪预览时可以取消“更新当前节点”另存。

## 编辑区层次

常用层：生成方式、必要参考、提示词、模型、尺寸／时长和生成按钮。文生图隐藏参考图入口，用户先切换编辑方式后添加参考，不自动改换模型。

可选层：提示词优化默认收起，由用户主动打开。原稿／建议分开，应用后才替换，优化失败不影响直接生成。文本生成直接归入文本节点，输入要求保留为草稿。

高级层：等价执行规格、版本／量化、参数限制、指定 Worker。默认分配相同规格的 Worker；首次配置优先可用规格，保存 profileId 后不静默回退到其他规格。不同安装路径不影响等价匹配。多个等价 Worker 聚合展示数量。

图片／视频／语音的指定 Worker 和文本语言服务选择都保存在草稿；重开编辑区不会丢失。模型或资源离线与任务排队分别展示。菜单使用统一深浅主题、键盘选择、Esc 收起及正文之外的弹层，不依赖操作系统下拉颜色。

## 数据职责

- 当前内容：kind、assetId / text / html、contentRevision、contentSchemaVersion=1。
- 创作草稿：generationDraft / videoDraft / speechDraft / textDraft；languageSelection 保存语言规格、Worker 及幂等请求。
- 任务：Server 校验并冻结参数、素材、执行规格、目标节点和提交时内容快照。草稿编辑不改变已提交任务。
- 结果：归档成功时持久化 NodeResult v1。Server、互联网 API、Worker 任务使用相同归档入口；本地媒体处理同步素材后走同一 Studio 结果 reducer。
- 版本：节点保存 versions；receivedResultIds 确保幂等采用。结果只有在类型及提交时内容快照仍一致时自动采用，否则只进入历史。参数草稿的修改不阻止当前结果采用。
- Server 不代替 Studio 写画布：结果账本独立于画布 revision。Studio 重连后读取并通过正常乐观锁保存，避免后台任务与用户画布操作互相覆盖。
- 撤销不回滚后台任务或结果账本。内容 revision 单调推进，已确认结果不因撤销被再次自动采用。

新结构显式版本化，未知内容版本由 Server 拒绝。后续多候选输出、更多操作类型、云端同步可扩展结果协议，不依靠节点名称猜测结果关系。

## 执行位置与验收

图片基础处理仍在 Studio；视频截取与提取音轨 Web 走 Server FFmpeg 单并发，Electron 走主进程内置 FFmpeg；AI 仍由已声明的 Worker 或语言 API 执行。未增加 GPU 调度、网络组网或积分机制。

本轮验收记录见 [节点创作验收](node-generation-acceptance-2026-09-29.md)。代码和界面测试与真实模型画质／性能验收分别记录。
