# 节点创作体验与后续模型接入

2026-09-26。用户确认按调研方案执行，分阶段实现；当前交付只覆盖第一阶段。

## 第一阶段：Qwen 创作面板（已实现）

节点外部固定屏幕尺寸编辑区，支持展开、内部参数与预览、离焦收起。参考缩略卡片可排序、设为构图基准，提示词与底部参数栏分层。明确区分模型边界与在线配置限制，不静默删输入、替换模型或修改提示词。

2512 仅文生图；2.1 支持文生图、指令编辑、多图参考与 RGBA。模型目录最大 10 张参考不等于当前部署承诺 10 张：当前云端样本覆盖最多 4 张。实际像素尺寸按配置与工作流对齐规则计算，不显示虚假 2K 档位。媒体处理位置继续按 PRD 的 Web / Electron / GPU Worker 分工。

## 第二阶段：IndexTTS

先确定并固定官方运行版本及适配器，再发布对应能力；优先评估 IndexTTS 2.5。音色参考、情绪参考、情绪文字/向量应按模式互斥展示。参考音频具备播放、截取及替换；不要把 MiniMax Speech 的音调、音量、音色强度滑块照搬为 IndexTTS 模型能力。

语速显示用户易懂的倍率，后端适配官方时长控制参数；精确秒数只有部署版本实际支持并通过验收才开放。原始输入、参考资产与版本归档。启动 GPU 前告知用户，在上海二 A 验证后再确定默认参数。

## 第三阶段：H3 视频

FL2VA 以文字、首帧、尾帧、首尾帧为输入模式；Ref2VA 以图片/视频/音频参考驱动生成或编辑，保留用户对 Ref2VA 的编辑语义。按实际工作流开放参考角色，不把上传的任意素材无差别塞入模型。

时长须由部署工作流可执行的帧数和帧率计算，展示实际值；输出音频开关需说明是模型能力还是导出静音，不把后期静音标成节省推理。分辨率、数量、时长及音频支持均由 Worker 配置声明。继续排除去字幕、片段重拍、360°全景。

## 第四阶段：可选提示词优化

H3 官方 h3-prompt-writing 是写作规则，需要语言模型执行，不能当成无需模型的内置服务。Qwen 2.1 官方文生图/编辑增强器也需要额外权重和资源。初版不擅自安装、下载或启动这些模型。

提供“优化提示词”主动操作，显示原稿与建议，用户应用后才替换；保留原稿以便还原。分别针对 Qwen 文生图、Qwen 编辑、H3 基础生成与参考生成建立模板和结构校验。未配置优化服务时不显示虚假的已开启状态；生成不强制依赖优化服务。无积分或会员收费逻辑。
