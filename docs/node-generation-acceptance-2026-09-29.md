# 节点原位生成与创作面板验收

日期：2026-09-29。Studio 0.15.0 / Server 0.13.0；Worker 未修改，任务协议保持 3.0。

## 实现范围

- 空节点显式切换类型，保留各类型草稿；有内容、历史、连线或在途/成功任务时锁定类型。自动名称随类型改变，自定义名称保留。
- 图片、视频、语音、文本生成归档到当前节点，重新生成保留历史，可采用历史或另存新节点。图片转视频、文本转语音创建明确的目标节点。
- 裁剪和视频截取默认原位更新；拼图、宫格、抽音轨保留各自的输出语义。Web FFmpeg 仍由 Server 执行；Electron 使用主进程与随包 FFmpeg。
- Server 冻结结果目标快照，持久化独立 NodeResult v1 账本；Studio 按结果 ID 幂等接收。编辑后的内容不会被迟到结果覆盖，已删除节点不会被恢复，重复轮询不会重复生成节点或历史。
- 编辑区保留草稿、进度、取消与重试；优化提示词折叠且需主动应用，Worker/规格详情放入高级区域。所有 Studio 下拉框统一深浅主题与键盘操作。

## Windows EXE 实测

通过原生 Windows UI 控制打包 Studio，使用打包 Server、隔离数据目录和本地文本 API 夹具，不使用真实密钥或用户项目。

1. 画布初始包含一个空文本节点和一个 2 秒视频节点。
2. 点击文本生成，结果写入原文本节点；原提示词仍在编辑区，编辑区未关闭，历史版本数为 1，内容类型已锁定。
3. 视频工具选择 0–1 秒，点击“处理并同步”。Electron 在本地下载缓存、调用随包 FFmpeg、同步结果。
4. Server 保存的画布仍为 2 个节点、0 条连线；视频节点内容版本变为 1，历史保存原视频和截取结果。
5. 重开视频工具显示 1 秒；随包 FFmpeg 读取并完整解码归档文件，确认时长 1.00 秒、H.264/AAC、160×90。
6. 隔离验收进程已退出，未修改用户 Server、Studio 数据或云 Worker。

可复用夹具：Studio `scripts/prepare-node-acceptance.mjs`。它仅准备隔离服务、素材和登录态；交互验收通过原生 UI 执行。

## 验证边界

- 本轮没有运行真实 GPU 模型；生成 UI 使用受控结果/本地文本 API，媒体处理使用真实 FFmpeg。
- 本轮没有验证 Linux/macOS 桌面打包。
- Vite 开发验收偶发 ResizeObserver 通知警告；本轮未屏蔽该警告，截图与交互断言通过。构建仍有大体积主包提示，可在后续按功能拆包。
