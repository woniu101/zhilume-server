# Worker 0.11 标准安装：阶段验收与阻塞项

**状态：安装器与核心发布验收已完成；完整推理环境安装、GPU 验收和基础镜像整机验收尚未完成。** 不把 Worker 0.10 复用已有环境的 GPU 成功样本算作本轮通过。

## 已实现

- ComfyUI 的 Linux x86_64 / Python 3.12 / CUDA 12.8 候选依赖锁：固定版本、发行包哈希，安装时不重新解析最新依赖。候选包含 Torch 2.8.0、torchvision 0.23.0、torchaudio 2.8.0 和 Transformers 4.57.6。
- IndexTTS 使用固定上游 `uv.lock` 并校验文件哈希，标准方案选择 Python 3.11；修正把核心 Python 3.12 用于语音安装会违反上游 `<3.12` 要求的问题。
- 下载前检查 Linux x86_64、glibc、基础工具、Python 版本和 24 GiB 最低磁盘余量。不自动安装系统 Python、驱动或系统包。
- 新目录安装，代码、venv、包缓存分开；安装目录不允许与 Worker state 嵌套。不会覆盖旧环境或改写已有执行器配置。
- 页面显示安装计划与阶段；计划变更后不能直接执行旧计划。页面/CLI 使用相同安装逻辑。取消安装回收受管进程组；失败进程组的主进程已退出时仍清理残留子进程。
- 安装结果仅标记 `installed-unchecked`，另行配置模型、检查、启动及真实推理。失败/取消保留清单和日志，用新目录重试，不假装支持断点续装。

## 已执行的验证

- Windows 全套 48 项回归：43 通过、5 项 Linux 专项跳过。覆盖无写入计划、版本/空间前置失败、锁定参数、失败/取消保留旧目录、计划过期、权限隔离和安装过程管理可响应。
- WSL2 Ubuntu 22.04 安装专项 7/7：包含真实 Linux 进程取消、失败主进程的子进程清理、含空格路径、错误 Python、低空间、失败记录与重复目录拒绝。磁盘不足采用注入值，不填满用户磁盘。
- `deploy/accept-portable.py`：在新目录实际安装 0.10.0 与 0.11.0 核心 wheel；验证无 Torch/Pillow、无 Server 绑定仍可访问静态页面和管理接口；运行中拒绝版本切换，停服升级/回退保留身份及凭证。
- 发布 wheel 已核对包含候选依赖锁。核心安装测试不安装 ComfyUI/IndexTTS 依赖，不运行模型。
- 管理页面真实浏览器回归通过（最终 28.3 秒）：深浅主题、窄屏、原有环境配置、只读安装计划、修改参数使计划失效、延迟到达的旧计划不重新启用安装按钮。首次多面板场景达到原 45 秒总时限，增加流程后的场景总时限改为 90 秒；单项请求/断言时限未放宽。
