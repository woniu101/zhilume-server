# 参考交互与短窗口布局验收

2026-09-29，Studio 0.16.1，Server 0.13.2 / Worker 运行代码未修改。

## 修改

- ComposerLayout 使用独立 div 滚动正文，内部 fieldset 只承担表单禁用，不让其固有布局约束挤压或覆盖固定区。
- H3 图片、视频、音频分别添加；直接展示参考卡片、文件名、标签、移除和媒体预览，单张卡片打开详细设置。首尾帧明确角色，支持移除。
- 音色参考直接展示文件、片段和原素材试听；保持替换/片段浮层组件位置稳定，选中素材时不会意外关闭正在编辑的浮层。
- H3 主界面显示中文生成方式，时长保留 124 帧对应的 5.17 秒。空表单移除重复提示，未配置和离线仍可见，参数错误仍禁用提交并保留原因。
- 文本生成的模型选择在可用宽度下与提交同行；更窄时换行。图片现有直接参考预览、拖动排序与移除保留。

## 验收

- 首轮图片、语音、视频、语言和四类焦点/布局共 16 项，14 通过；1 项仍预期旧技术标识 FL2VA，更新为中文；另 1 项发现未配置语音状态重复，修复重复渲染。
- 修正后图片、语音、视频及新参考布局专项 13/13 通过。新用例包含图片/视频/音频混合参考、长文件名、标签插入、片段修改、移除和重新添加；在 900×600、700×520、1100×720 深浅主题检查正文与固定区域不重叠，操作区能被实际鼠标命中。
- 构建通过。未执行 GPU 或互联网计费推理；生成提交使用协议夹具，素材上传和画布保存使用隔离 Server。

本轮落实布局、参考操作与参数表达。音色库、流式文本、更多模型和高级编辑仍是后续独立功能。
