# 统一参考素材浏览验收

Studio 0.21.0，Server 0.15.0。仅修改 Studio 界面与交互；Server、Worker 运行代码不变，PRD v0.42，协议保持不变。

## 交付

- 图片参考、视频首尾帧/全能参考/替换、语音音色/情绪参考采用共享 `ReferenceBrowser`，替代仅显示文件名的下拉。
- 支持名称搜索、无匹配状态、已选标记、图片缩略图和独立的预览/试听动作。点击预览不改变参考；点击卡片才选用。原有上传、拖入、排序、角色类型及片段设置继续保留。
- 预览不自动播放；搜索、选择或关闭浮层时卸载预览媒体。音视频候选默认只显示类型图标，点击预览才加载播放器。每批渲染 24 项，可显示更多；这不是服务端分页或大型素材库性能验收。
- 选择器采用已有宽浮层，居中并限制在窗口内；浮层自身滚动，主编辑区不被撑高。深浅主题、键盘 Enter 选用、Esc 关闭与焦点返回沿用统一浮层机制。

## 验证

14 个不同浏览器用例分批通过：图片工作流 8、短窗口参考布局 1、语音 2、视频 2、新增素材浏览综合用例 1。新增用例覆盖 27 张图片的分批显示/搜索、无匹配提示、预览不选用、类型筛选、音视频不自动播放、键盘选用、草稿保存与重开。

首轮为 13/14，新用例在自动保存前读取尚不存在的 videoDraft 字段而抛错；修正等待断言后通过。调整预览位置及宽浮层后再做相关专项回归，不重复累计用例数。既有开发模式 ResizeObserver 通知仍存在，未隐藏。

本轮使用本地图片、音频、视频和显式模拟模型目录/生成响应；保存走真实 Server 接口。没有启动 GPU，也没有重复 Windows 原生 UI 验收。打包检查与浏览器交互验证分开记录。

最终 TypeScript、生产构建和 `npm run pack` 均通过。`release/win-unpacked/Zhilume Studio.exe` 包内版本 0.21.0，ASAR 中 3 个应用构建文件与最终 dist 逐字节一致。生产构建仍有既有大分包提示。

900×600 小窗口截图已检查：[深色](evidence/reference-browser-dark-2026-10-03.png)、[浅色](evidence/reference-browser-light-2026-10-03.png)。预览媒体保持比例，滚动限定在浮层内，主编辑区尺寸不随选项展开变化。

## 范围

本轮没有新增模型、音色收藏库、跨 Server 资产复用或服务端素材检索。素材候选沿用当前服务提供的资产集合，按参考角色过滤；项目权限隔离不由客户端搜索承担。
