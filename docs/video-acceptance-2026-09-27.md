# H3 视频开发与验收

日期：2026-09-27。Studio 0.12.0 / Server 0.9.0 / Worker 0.8.0，操作目录 1.6.0，协议 2.0。

## 实现

视频空节点单击打开节点外部编辑区，支持文生视频、首帧、尾帧、首尾帧和 Ref2VA 全能参考。切换保留输入，参数按在线 Worker 配置约束；上传加入素材库，离焦保存草稿，相同参数重试复用提交身份。没有积分和未接入的提示词优化开关。

H3 与图片共用 ComfyUI 提交、取消、重启对账和输出归档流程；与语音共用子进程超时/取消。Server 校验显式参考角色与配置指纹，通过主动连接传输入并拉输出，不需要公网回调。视频参考只使用画面，音频参考独立提供；不能把它当作逐帧编辑工具。

## 云端实测

上海二 A，RTX 5090 32 GiB、14 CPU、48 GiB 内存；固定 ComfyUI 提交 `79be670e2d9be63e238785af307369d2b9039ed1`，原生节点、PyTorch attention、关闭 xFormers 与自定义节点。公共 `/model/ModelScope/Comfy-Org/MiniMax-H3` 的两份 pruned int8 convrot 扩散模型、Qwen3VL 32B NVFP4 AWQ、视频/音频 VAE 共五个文件直接软链接，没有下载模型。

五种输入模式均通过真实 ComfyUI `validate_prompt`，未以模型可见或工作流有效替代 GPU 测试。以下 GPU 样本均为 512×288、124 帧、24 FPS，标准 20 步（取消样本 50 步）。

| 样本 | 实际结果 | Server 提交至归档/停止 |
|---|---|---|
| 文生视频 | H.264 MP4、124 帧，32kHz 立体声 | 38.57 秒 |
| 首尾帧 | 两个显式图片角色，MP4 静音输出 | 24.33 秒 |
| Ref2VA | 图片＋视频＋音频组合参考，视频/音频各取 56 帧；输出含声音 | 78.68 秒 |
| 执行中取消 | 指定 prompt 取消，未归档输出 | 12.23 秒（含主动等待 10 秒） |
| 取消后新任务 | 使用新种子重新推理，MP4 与音轨检查成功 | 21.17 秒 |

本机 Server 全程没有监听入站端口，输入上传、结果拉取、SHA-256 与 provenance 归档均成功。最后 ComfyUI 运行/等待队列为空，实例状态已核实为 **Stopped**。最终 Worker 0.8.0 安装到独立目录 `/opt/zhilume-worker-0.8.0`；原图片服务开机配置保留，H3 未设为自动启动，未制作/发布镜像。

一次参考请求使用了 2.111 秒音频，却指定 56 帧（2.333 秒），被实际时长校验拒绝，未提交 GPU。换成足够长的已生成测试语音后成功；没有通过填充或静默缩短规避校验。

验收数值与媒体轨道见 [结构化证据](evidence/h3-2026-09-27.json)。耗时是该实例、该输入的端到端样本，包含缓存状态差异，不能泛化为 SLA。Ref2VA 执行时一次显存采样为 31858 MiB，未做连续峰值测量。

## 验收边界与后续

本轮证明基础生成及完整任务链路，不证明参考遵循度、音画同步质量、音色相似度或提示词效果达到产品目标。首帧/尾帧单独模式只有真实工作流校验，未分别生成样本；首尾帧样本使用相同图片，尚未检验不同首尾图片的过渡质量。

高分辨率、竖屏、长视频、参考上限、华北二 A、新镜像冷启动、OOM/驱动异常、长时断网和语音/图片/视频共卡切换仍待验证。profile 保持 `unverified`，不把一个实例的样本扩展成全部配置已验收。下一阶段为主动触发、可审阅后应用的提示词优化，不默认安装新权重或隐式改写用户输入。
