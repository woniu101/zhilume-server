# 内容尺寸与局部避让验收

Studio 0.20.1，配套 Server 0.15.0，Worker 0.12.1。本轮仅修改 Studio 运行代码，协议不变，PRD v0.41。

## 行为

此前媒体解码完成后只修改自身宽高，竖图会盖住下方节点，宽视频也可能盖住同排节点。现在由共享内容布局模块处理尺寸和受影响的同级节点：固定新内容节点位置，碰撞节点向下避让；未碰撞的列、连线、视口保持不变。成员扩张会同步增大分组边界，分组与外部节点碰撞时按整体处理。

自动尺寸只对当前内容适配一次。生成、替换、上传及历史内容采用共用媒体尺寸回调；旧素材迟到回调不影响新内容。手动拖拽/缩放、已知尺寸媒体重复加载与重开不触发布局。内容缩小不自动回收空白；不会全局重排已经存在的手工重叠。

异步尺寸也补全匹配内容的历史快照，生成采用与避让可一次撤销；不会把别的用户编辑吞进额外的布局撤销步骤。

## 边界

本轮没有重新进行 Windows 原生 UI 操作或真实生成。打包校验只证明 EXE 中的应用资源与受测构建一致。自动布局限定为内容扩张，不提供全画布自动整理、拖动吸附或紧凑回收。
