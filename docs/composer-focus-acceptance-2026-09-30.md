# 底部工具栏与专注编辑验收

2026-09-30，Studio 0.17.0 / Server 0.13.2；Worker 运行代码未修改，PRD v0.37。

## 行为

- 四类共享 ComposerChrome / ComposerLayout，顶部保留模式与历史、展开入口，取消关闭 X；类型选择移动到底栏。图片、文本模型仍直接选择，单一视频/语音模型显示真实名称，H3 不再重复显示模式。
- 底部类型、模型、常用参数、辅助操作与生成按组排版，窄窗口换行。优化提示词采用带名称与提示的图标入口；情绪设置位于语音底栏。所有主生成按钮统一“生成”，离线状态独立显示，手动正文保存仍为“保存文本”。
- 专注编辑填满视口（四周 16px），背景遮罩阻止画布点击，键盘焦点保持在编辑区或 Portal 子浮层。提示词随剩余高度伸展，正文滚动与固定底栏分离。
- 展开/还原沿用同一表单树，保存草稿与普通模式滚动位置。Esc 依次关闭子浮层、还原专注编辑、收起普通编辑区。保留有效离线规格排队、未配置/非法输入禁用、幂等提交、取消/重试和结果版本归档。

## 排查与验收范围

- 代码核对：文本生成与保存；图片文生/单图编辑/多图参考；H3 五种模式与混合媒体参考；IndexTTS 参考音色、情绪与语言/语速。未新增模型能力、音色库、音乐/音效或流式文本。

- 首轮 19 项中 16 项通过，3 项查找旧 H3 文案或旧优化按钮名称，已同步新交互预期。
