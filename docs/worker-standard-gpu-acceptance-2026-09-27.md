# Worker 0.11 标准环境 GPU 验收

2026-09-27，上海二 A，RTX 5090 32GB，驱动 610.57.04。使用此前由标准安装器新建的 ComfyUI / IndexTTS 独立环境，未回退到旧推理环境。Worker 0.11.0 / Server 0.10.0，协议 3.0。

## 环境与范围

- ComfyUI Python 3.12.3 / Torch 2.8.0+cu128；IndexTTS Python 3.11.16 / Torch 2.8.0+cu128。固定代码修订、依赖锁及安装清单沿用 [标准安装验收](worker-standard-install-acceptance-2026-09-27.md)。
- 核心显式安装可选 Pillow 12.3.0 做图片输入/输出校验，未安装 Torch。Qwen/H3 共享新 ComfyUI 托管服务；IndexTTS 使用新 Python 和程序目录。
- 只链接现有模型文件，不下载或复制权重。旧程序环境保留，部署配置变更前备份；身份、任务凭证和管理凭证未替换。
- 实际比较 Qwen 2512 与 IndexTTS 的 profileId：变更 Python / 程序路径前后相同。Qwen 2.1 的新增规格使用实际权重 SHA-256，不沿用名称猜测身份。

## GPU 结果

| 场景 | 结果 |
| --- | --- |
| Qwen Image 2512 文生图，512×512 / 5 步 | PNG 318,214 字节，Server 校验哈希并归档 |
| Qwen Image 2.1 文生图，512×512 / 5 步 | PNG 292,464 字节，归档成功 |
| Qwen 2.1 单图指令编辑，5 步 | PNG 1,008,828 字节，抽查看到蓝杯改为黄杯 |
| Qwen 2.1 双图参考，5 步 | PNG 1,050,367 字节，抽查看到蓝杯与红壶同框 |
| IndexTTS 中文合成，2 秒音色参考 | PCM16 / 24kHz 单声道 WAV 145,528 字节，归档成功 |
| H3 FL2VA 文生视频，512×288 / 124 帧 / 20 步，含音轨 | MP4 144,412 字节，视频、音轨及归档哈希校验通过 |
| H3 执行中取消并停止共享 ComfyUI | 约 7 秒完成，任务 cancelled，相关执行器停用，显存回到 2 MiB |
| 再启动共享服务并生成图片 | 成功；正常等待停止通过 |
| 正常重启 Worker | 旧受管进程消失，显存 2 MiB；身份及凭证哈希不变，推理服务不自动启动，显式恢复成功 |

一般任务结束后显存约 746–752 MiB；服务停止后约 2 MiB。Server 未监听入站端口，主动传输输入并取回结果。图片样本采用低步数，验收的是执行、输入角色与归档，不作为最终画质基准；H3 仅覆盖 FL2VA 文生视频与取消，未重测首尾帧或 Ref2VA。

## 管理响应与网络失败的区分

首轮 8 项任务均达到预期终态，但 104 次管理采样中有一次 `fetch failed`，因此首轮脚本整体判定失败，保留原始记录。公网路径复测又遇到云平台转发返回 HTTP 502；不能把这两次失败删除后宣称公网链路稳定，也不能仅凭第一次通用错误确定根因。

随后增加两种独立观测：

- Worker 本机回环接口连续采样 180 次，0 失败，其中任务活跃采样 27 次；P95 184ms，最大 265ms。
- 操作者临时 SSH 转发路径下重测 H3 取消、停止、显存释放及恢复生成，全部通过；管理采样 27 次，0 失败，任务活跃采样 13 次，P95 376ms、最大 470ms。

临时转发仅为本轮运维验收工具，结束后关闭，不进入 Worker / Server / Studio 产品，不要求 Server 有公网地址。数据支持 Worker 在本次负载下可响应，但云平台公网转发的稳定性仍不能判通过。

## 控制与交互回归

- Server 路由/调度/传输 4/4：不同能力、精确规格、物理资源归属、多 Worker 并行、排队、离线绕过、依赖失败、取消、冻结参数、重复提交及无入站监听。
- Worker 管理 9/9：权限分离、故障隔离、资源锁和检查操作不阻塞控制循环等。
- Studio 浏览器 13/13：图片/语音/H3 面板、参考角色、离线可编辑、重试幂等、批量/流程绑定及语言服务密钥不回显。

多 Worker 并行使用轻量真实 Worker 和协议夹具，不冒充两张物理 GPU。Studio 测试使用接口夹具覆盖交互，真实 GPU 传输与归档由 Server 脚本另行覆盖；未重新执行完整 Electron 原生交互验收。
