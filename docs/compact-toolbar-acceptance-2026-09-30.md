# 紧凑底栏与居中放大编辑

Studio 0.18.0，Server 0.13.2，PRD v0.38。本轮仅修改 Studio 编辑器交互，未运行 GPU 推理。

## 实现

- 共享底栏分成左侧选项组与右侧提交列。类型、模型、参数、辅助操作按内容宽度排列；左侧允许换行，生成按钮与最后一行对齐。长模型名称截断，不撑开面板。
- 四类生成接入同一个按钮，统一 16px 向上箭头、36px 高度和提交中状态；手动保存仍为“保存文本”。
- Select 提供 toolbar / field 两种正式变体，工具栏透明紧凑，表单保留边框。统一 SVG 箭头、选中勾、悬停状态与菜单行高；菜单根据内容调整宽度。
- 优化入口使用星光图标和“优化”，情绪入口简写为“情绪：跟随/参考/手动/描述”；参数与辅助操作共用轻底色、圆角和展开状态。非默认情绪有轻微强调。
- 放大编辑最大宽度 860px、水平居中，常规窗口上下留 40px，小窗口留 16px。遮罩可点击还原，保留草稿、参考和普通滚动位置，不穿透到画布。
- 子浮层拥有关闭它的指针事件；该标记保留到事件结束，避免 React 卸载浮层后同一次点击又触发父面板还原。Esc 和点击遮罩均一次只退出一层。

## 验收记录

- 新增长语言模型名称、右侧按钮边界、窄窗口布局、四类遮罩还原和子浮层优先关闭的交互检查。
- 首轮专项发现遮罩点击会同时关闭浮层和放大面板，已在共享浮层事件处理中修正。运行中修改源码触发过 Vite 热更新，最终结果以停止修改后的完整回归为准。
- 最终浏览器回归 **21/21 通过（3.5 分钟）**：composer-focus-mode、generation、language-tools、speech、video-generation、reference-layout、editor-focus、node-results。长名称不挤压按钮；四类节点在深浅主题下保持底栏边界，遮罩一次只退出一层并保留草稿。
- 截图位于 `evidence/0.18.0/`，包含四类普通/放大布局、深浅主题与长模型名称。已人工查看图片、音频普通底栏。
- 开发环境仍有既有 ResizeObserver 通知警告，构建仍提示大分包；没有屏蔽警告，几何和交互断言通过。协议夹具不等同于真实 GPU 推理验收。

## 打包与桌面验收

- `npm run pack` 成功，生成 Studio 0.18.0 Windows EXE；读取 app.asar 确认版本为 0.18.0，包内 3 个 dist 文件与本次构建逐字节一致。
- 在独立测试 Server 和实际打包 EXE 中验证文本节点：底栏显示紧凑模型选择器及“↑ 生成”；放大编辑宽度 860px 并居中，两侧保留半透明遮罩。
- 展开语言模型菜单后，首次点击遮罩仅关闭菜单，面板保持放大；再次点击遮罩还原普通面板，原有文本草稿保持不变。
