# 上海二 A IndexTTS 2.5 真实 GPU 验收

2026-09-27；Studio 0.11.0 / Server 0.8.0 / Worker 0.7.1。已完成服务端到真实 GPU 的功能闭环，声音自然度与音色相似度仍需人工试听。没有发布镜像。

## 环境与边界

- 上海二 A `cn-sh2-01`，RTX 5090 32GB，14 vCPU / 48 GiB，驱动 610.57.04。准备依赖时先以 2 核 4 GiB 无卡模式启动，再通知用户切换 GPU。
- 独立 IndexTTS 环境 Python 3.10.15，torch/torchaudio 2.8.0+cu128，transformers 4.52.1，bf16；上游固定 `ee40fa7d6c6b8a2c7f06105f9f1e65775b74868c`，未修改上游源码。Worker Python 3.12.3。
- `/model` 实际具备主模型、文字情绪模型、w2v-bert、BigVGAN、CAMPPlus。最终部署清单链接 24 个准确文件，未下载或复制模型权重；Python 依赖另行安装。CAMPPlus 公共文件为 `.pt`，严格加载键/形状通过后链接为上游要求的 `.bin`。
- 停止 ComfyUI，仅启用语音执行器；没有测试图片/语音共用显存时的自动切换。Web/Electron 普通视频处理架构未改变。
- 本机 Server 通过 HTTPS/WSS 主动访问云 Worker，测试 Server **没有监听任何入站端口**。使用独立项目与 Server/Worker 身份，不修改用户项目。
- 参考为官方 [voice_03.wav](https://huggingface.co/spaces/IndexTeam/IndexTTS-2-Demo/resolve/main/examples/voice_03.wav)、[voice_04.wav](https://huggingface.co/spaces/IndexTeam/IndexTTS-2-Demo/resolve/main/examples/voice_04.wav) 演示素材，仅作技术测试。来源和 SHA-256 写入证据，原始音频未提交仓库。

## 真实结果

统一测试文本：“你好，欢迎使用织镜。今天我们一起，把脑海中的灵感变成作品。”音色参考取前 5 秒；独立情绪参考取另一素材第 1–5 秒。每个任务都启动独立进程，耗时包含模型加载、文件传输及归档；不是纯推理耗时。

| 场景 | 状态 | 总耗时 | 输出音频时长 |
|---|---|---:|---:|
| 跟随音色、1 倍 | 成功 | 71.66 秒 | 4.191 秒 |
| 1.5 倍语速 | 成功 | 30.27 秒 | 2.891 秒 |
| 0.75 倍语速 | 成功 | 30.27 秒 | 5.538 秒 |
| 开心情绪向量 | 成功 | 30.33 秒 | 4.191 秒 |
| 文字情绪 | 成功，最终清单复测 | 33.56 秒 | 4.272 秒 |
| 独立情绪参考 | 成功 | 32.47 秒 | 3.831 秒 |
| 长文本开始推理后取消 | 已停止，无归档产物 | 29.80 秒 | — |
| 取消后的新任务 | 成功 | 30.80 秒 | 4.389 秒 |

首个任务包含中文规范化 FST 缓存构建。语速变化方向与预期相符，但不能将倍率理解成精确目标时长；模型采样也会造成重复任务时长差异。

所有成功样本均为 24kHz / 单声道 / PCM16 WAV、非静音，通过传输 SHA-256 校验；参考角色、片段与实际参数归档。重复提交相同 requestId 返回同一任务，没有重复生成。功能成功不代表主观情绪表达或音色相似度已经达标。

约每 2 秒显存采样，观察最大 7410 MiB；不能视为瞬时峰值或所有文本的显存上限。取消日志已出现 `starting inference`；取消后无 speech_runner / CUDA 计算进程，显存约 2 MiB，后续任务成功。真实 GPU 崩溃、OOM、长时断网和异常强杀恢复未覆盖。

## 实测发现并修正

最初链接完整情绪模型目录时，文字情绪成功；改为精确文件清单后，因遗漏 `chat_template.jinja` 复测失败。失败任务未归档产物，也没有自动重复生成。

最终清单补齐聊天模板、added_tokens.json、special_tokens_map.json。Worker 预检新增情绪分词文件及非空聊天模板检查，缺少时不发布可执行配置。补齐后使用最终目录重新合成通过；没有临时修改上游模板或用硬编码提示词绕过问题。
